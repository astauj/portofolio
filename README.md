## File yang harus kamu ganti

Masukkan file milikmu ke folder `assets/`:

1. `profile.png`
   - foto kamu sebelum berubah
2. `spiderman.png`
   - gambar Spider-Man yang muncul setelah foto diklik
3. `playlist.jpg`
   - cover playlist Spotify
4. `project-1.jpg`
5. `project-2.jpg`
6. `project-3.jpg`
7. `resume.pdf`
8. `certificates/cert-1.jpg`
9. `certificates/cert-2.jpg`
10. `certificates/cert-3.jpg`

Kalau belum punya gambar, website tetap tampil dengan placeholder.

## Cara mengubah teks
Buka `index.html`, lalu cari teks yang ingin diubah.

## Cara mengubah Spotify
Di `index.html`, cari:
`https://open.spotify.com/`
dan ganti dengan link playlist Spotify milikmu.

## Cara menjalankan
Cara paling mudah:
- buka folder ini di VS Code
- install extension Live Server
- klik kanan `index.html` -> Open with Live Server

Atau upload repository ke GitHub lalu deploy di Vercel.

## Penting
Efek petir dan bintang dibuat dengan CSS + JavaScript, jadi tidak membutuhkan video petir besar.
